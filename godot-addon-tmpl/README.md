# MY_GODOT_ADDON

A minimal Godot 4 addon template.

## Contents

- `addons/my_godot_addon/`: a plugin skeleton that prints `Hello, World!` when enabled.
- `examples/main.tscn`: an empty default scene.

## Getting started

1. Open the project in Godot 4.
2. Enable **MY_GODOT_ADDON** in **Project > Project Settings > Plugins**.
3. Run the project to open the empty default scene.

## Development

just check
